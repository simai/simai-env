# simai-env v1.41.0

Release date: 2026-11-05

## Summary

Larena Panel: a site's own nginx directives.

- **Own directives per site.** `site:nginx-custom` sets nginx directives
  that the site's profile does not cover (an extra `location`, headers,
  `client_max_body_size`, rewrites); `site:nginx-custom-show` shows them.
  They live in `/etc/nginx/simai-custom/<project>.conf`, included in the
  site's HTTP and HTTPS servers.
- **A mistake repairs itself.** The directives apply only when nginx accepts
  them; if the site stops answering they are undone at once; and every
  change is undone after two minutes unless it is confirmed with
  `change:confirm`, the same way as firewall and panel access changes.
- New sites include the file; sites made before get the include the first
  time directives are set. Removing a site removes its directives.

Administrator only.

The local stand keeps its state: `stand.sh up` starts a stopped stand
instead of recreating it.

Recorded panel answers move to set 17.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```

## Verification

- `nginx_custom_e2e` (new): a new site includes an empty file, a plan
  changes nothing, directives apply and show with the pending change,
  confirm keeps them, a directive nginx rejects changes nothing and is
  named, directives that take the site down are undone, an unconfirmed
  change is undone by its timer, an older vhost gets the include, empty
  directives remove the file; through the gateway: show, owner refusal, a
  plan, a job with the change id, `change:confirm`; the site's removal
  removes the file.
- Ubuntu 22.04, 24.04 and 26.04.
