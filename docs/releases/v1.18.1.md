# simai-env v1.18.1

Release date: 2026-10-21

## Summary

In 1.18.0 the `deny` patterns of a node site with a static root became regex
locations. nginx does not evaluate regex locations for a path that matches a
`^~` prefix location, so a denied name inside such a prefix (for example
`/simai/.htaccess` or `/runner/.env`) was served. Deny patterns now run at
server level before location selection, and hidden files are always denied
on these sites (ACME challenges excepted).

No site on a released host used 1.18.0 routes before this fix.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

Sites pick the new routes up on their next deploy.

## Verification

- `app_e2e` (26 checks) on Ubuntu 24.04 and 26.04: `/simai/.htaccess` and
  `/runner/.env` answer 404 inside prefix locations.
- CI on Ubuntu 22.04, 24.04 and 26.04.
