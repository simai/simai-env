# simai-env v1.12.75

Release date: 2026-07-11

## Summary

This release completes a full audit of the interactive menu and all registered
operations. It strengthens safe confirmations and rollback behavior, reduces
Advanced-menu overload, improves terminal usability and adds explicit coverage
for every registered command.

## Highlights

- Site creation now defers host/profile writes until the final default-no
  confirmation and rolls back only resources created by the failed invocation.
- Empty Enter, EOF, Escape and pre-command cancellation have predictable,
  truthful behavior.
- Managed-state menu operations use explicit confirmation contracts.
- Advanced Sites, System and Bitrix operations are grouped into focused
  submenus while routine shortcut numbers remain stable.
- Whiptail geometry and result tables adapt to terminal size; long non-TTY
  operations emit elapsed-time heartbeats.
- Root and section help are generated from the command registry.
- All 131 commands have machine-readable coverage classification and a Linux
  dispatcher harness.

## Security and operational safety

- Deprecated password-in-command examples were removed.
- Unexpected positional arguments now fail closed.
- Regression smoke is read-only by default; synchronization and destructive
  fixtures require explicit safety switches.
- Full cleanup verifies sites, paths, metadata, databases/users, nginx, PHP
  pools, cron, queues, archives and temporary files.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update
```

After updating:

```bash
sudo /root/simai-env/simai-admin.sh self status
sudo /root/simai-env/simai-admin.sh profile validate
```

No data migration is required. The pre-update archive created by the updater is
the rollback source if validation fails.

## Verification

- local syntax, ShellCheck, smoke invariants and correction regressions: PASS;
- command registry: 131 classified, 131 dispatcher routes verified;
- text and whiptail contracts at 60x20, 80x24 and 120x40: PASS;
- test-server read-only smoke and full disposable regression: PASS;
- protected six-site baseline: unchanged;
- final disposable-resource residue: zero.

## Known limitations

No open finding remains in the audited scope. GitHub Actions remains the final
independent verification after publication.
