# simai-env v1.27.0

Release date: 2026-11-01

## Summary

For the sites list and staff spaces of Larena Panel:

- **Is the site up?** Each site in `self describe` and `site describe` has
  `answers`: the HTTP status of its health path (`health.path` of
  `.simai/app.json`, else `/`), asked through nginx on 127.0.0.1 without
  following redirects, and when that was checked.
- **Disk.** `disk` is the size of the site directory; each owner has
  `sites_disk_bytes`, the sum of the owner's sites.
- **Backups.** `last_backup` is the time of the newest data backup.
- `self status-refresh` measures answers (every run) and disk (at most hourly)
  into `/var/lib/simai-env/site-status.json`. Cron runs it every five minutes
  (`/etc/cron.d/simai-site-status`), installed by `self migrate` (and so by
  `self update`) and by `panel install`, so a description never waits for
  sites.
- **Blocking an owner.** `owner block --name N` expires the owner's account,
  so SSH and SFTP stop and open sessions end, and the panel gateway refuses
  every request made as that owner (`owner_blocked`). The owner's sites keep
  serving and keep running as the owner. `owner unblock` restores access.
  Both are in the gateway for administrators; the host description shows
  `blocked` and `blocked_at` for each owner.

Recorded panel answers move to set 4: the new fields, and plans for
`site:set-php`, `owner:create`, `owner:block` and `site:add` with the
laravel profile.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```
