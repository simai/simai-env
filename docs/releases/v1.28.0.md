# simai-env v1.28.0

Release date: 2026-11-01

## Summary

For the backup, PHP, server, database and log screens of Larena Panel:

- **What the server allows.** `self:describe` carries `gate.commands`, the
  commands this panel user may call; the panel shows only those actions.
- **Backups.** `backup:data-restore {domain, backup, db, files}` restores a
  backup by name. Before the database is replaced, the current one becomes an
  ordinary backup, listed with the others and restorable the same way. Files
  are extracted next to the site for review, never over the live files.
  `backup:data-verify` checks a backup and test-imports its dump;
  `backup:data-schedule` sets the daily time and how many to keep (1-90).
- **PHP.** `php:extensions {php}` lists loaded and available extensions.
  `site:php-ini-list|set|unset` change a site's PHP settings from an allowlist
  (`memory_limit`, `upload_max_filesize`, `post_max_size`,
  `max_execution_time`, `date.timezone` and others), each value checked by
  its own rule, applied to the site's pool at once.
- **Server now.** `self:metrics`: CPU load, memory, swap and disks, for
  administrators.
- **Databases.** `db:list` lists the sites' databases with engine, size and
  user, without passwords; owners see only their own. `site:db-rotate` sets a
  new password that goes only into the site's `.env` and `db.env`.
- **Logs.** `logs:nginx` takes `match`, a fixed string.

Fixes on the way:

- `site db-rotate` left `.env` owned by the wrong account and a cached
  Laravel config with the old password; it now keeps the owner, rebuilds the
  cache and restarts workers.
- A backup taken in the same second as another wrote into it; it now waits
  for a new name. A manual backup without `--keep` no longer prunes a site
  with a longer schedule down to seven.

Recorded panel answers move to set 5 (46 files): the new reads, plans for
every new action and an `owner_scope` refusal for each.

SFTP accounts in the panel (`access:*`) are not in this release.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```
