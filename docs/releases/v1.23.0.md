# simai-env v1.23.0

Release date: 2026-10-29

## Summary

SIMAI ENV Panel can now be installed on a server, as FastPanel is: with the
server or later, by one command.

```bash
sudo /root/simai-env/simai-admin.sh panel install --domain panel.example.com --ssl-email ops@example.com --confirm yes
```

- The panel is its own isolated site; its account may run only the panel
  gateway (`docs/architecture/panel-gate.md`), nothing else as root.
- Until the Larena build is ready the site holds a placeholder that checks
  the whole path (site account, sudo, gateway) and shows no server data. The
  build is installed the same way with `--git/--ref` or
  `--archive/--sha256` and replaces the placeholder.
- The install prints a one-time first sign-in link once; it never reaches a
  log. `panel setup-link` replaces it.
- `panel remove` removes the panel site and its gateway access and leaves
  every other site alone. `panel status` shows the installed panel.
- `install.sh` installs the panel with the server when
  `SIMAI_INSTALL_PANEL_DOMAIN` is set (`SIMAI_INSTALL_PANEL_EMAIL` requests a
  certificate).

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

Nothing changes on servers that do not run `panel install`.
