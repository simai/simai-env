# simai-env v1.17.4

Release date: 2026-10-21

## Summary

Node services (profile `node`) get `SIMAI_STATE_DIR=<site root>/shared/state`
in their unit: a directory outside releases, owned by the site user, that
survives deploys and rollbacks. It is the same directory a manifest entry
`"shared": ["state"]` links into every release, so either way of reaching it
works. Used by admin.simai.io (the ui-admin mock API keeps its data there).

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

Existing node services pick the variable up on their next deploy or
`site service-restart`.
