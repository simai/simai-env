# simai-env v1.39.0

Release date: 2026-11-04

## Summary

Larena Panel, the file manager, part 1.

- **Browse and edit.** `file:list`, `file:stat` and `file:read` show a site's
  directories and text files; `file:write` saves a text file atomically and,
  with the `sha256` from `file:read`, refuses to overwrite a change made
  meanwhile.
- **Organise.** `file:mkdir`, `file:rename` (also moves within the site) and
  `file:remove` (a file, a link, or a directory with its contents).
- **Download.** `file:download` answers one line with the size and then the
  raw bytes, up to 1 GiB.
- **Safe by construction.** Every operation runs as the site's user inside
  the site directory, never as root; paths are walked without following
  symbolic links, so `..` or a link to `/etc` never lead outside. Owners use
  it on their own sites; another owner's site is refused.

Uploads, archives and extraction come next.

Recorded panel answers move to set 15.
