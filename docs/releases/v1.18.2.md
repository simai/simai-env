# simai-env v1.18.2

Release date: 2026-10-21

## Summary

Routes generated for node sites with a static root (1.18.0-1.18.1) served
HTML and other text without a charset, unlike the static profile (1.17.3) and
the previous playground host. They now set `charset utf-8` for HTML, plain
text, XML, CSS, JavaScript, JSON and SVG. `self migrate` (run by
`self update`) renders the routes of existing sites again from their current
release, with `nginx -t` and the previous files restored on failure.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `app_e2e` (29 checks) on Ubuntu 24.04 and 26.04: HTML and JavaScript carry
  `charset=utf-8`; routes without it are rendered again by `self migrate`
  exactly once. `upgrade_e2e`.
- CI on Ubuntu 22.04, 24.04 and 26.04.
