# simai-env v1.36.0

Release date: 2026-11-03

## Summary

Larena Panel stage 7: certificates through Cloudflare DNS.

- **DNS challenge.** `ssl:letsencrypt {challenge: dns}` proves the domain
  with a TXT record instead of a file on the site, so HTTPS can be ready
  before the domain points at the server, and a wildcard certificate can be
  requested from the panel (`wildcard: yes`).
- **One token per server.** `ssl:dns-credentials {provider: cloudflare,
  token}` stores the Cloudflare API token once, root-only; requests and
  renewals use it. It is never shown, kept in a job record or logged;
  `ssl:dns-status` only says whether it is set. Administrator only;
  `remove: yes` deletes it.

Recorded panel answers move to set 12.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```

The token needs `Zone:DNS:Edit` on the zones of the sites.

## Verification

- `panel_e2e`: an owner cannot store a token, a malformed token is refused,
  a DNS challenge without a token fails, the stored file is root 0600 and
  the token is in no job record or log, `ssl:dns-status` shows it is set
  without the token, Certbot is called with the stored credentials and no
  webroot, renewal keeps the DNS challenge, the token can be removed.
- Ubuntu 22.04, 24.04 and 26.04.
