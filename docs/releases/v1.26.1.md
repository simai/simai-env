# simai-env v1.26.1

Release date: 2026-10-31

## Summary

A clean install of 1.26.0 found two problems that the test containers did not
show:

- `install.sh` leaves only the core profiles enabled, and the panel is a Laravel
  site, so `panel install` (and `--with-panel`) was refused on a new server.
  `panel install` now enables the laravel profile.
- `install.sh` defaulted to Percona Server, which has no packages for Ubuntu
  26.04, so the installer failed there unless `SIMAI_INSTALL_DB` was set. The
  default on 26.04 is now MySQL from the Ubuntu repository.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `install.sh --with-panel` on a clean Ubuntu 26.04 container, from the tag.
- `panel_install_e2e` now starts from the core profiles, as a new server does.
- CI on Ubuntu 22.04, 24.04 and 26.04.
