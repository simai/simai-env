# simai-env v1.22.0

Release date: 2026-10-29

## Summary

Stages 3–4 of the gateway for SIMAI ENV Panel
(`docs/architecture/panel-gate.md`): with them the panel can do through the
gateway what an administrator does day to day.

- **Deploys.** From a git repository and ref, or from a release archive the
  panel sends right after the request line. The gateway checks the size and
  the sha256, runs the deploy as a job and removes the archive afterwards.
- **Sites.** Create (static, PHP, Laravel, WordPress, Node, redirect; PHP
  version, database, owner), switch PHP, remove (optionally with files and
  database), create or drop the database, path redirects, the Laravel
  scheduler entry, removing a certificate.
- **Owners.** Create with an SSH key sent as text, add a key, remove.
- **Owner limits.** A panel user acting as an owner creates sites only for
  that owner, acts only on that owner's sites and cannot manage owners.

Every action answers a plan first and runs as a job only when confirmed.
Command-line use is unchanged.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```
