# simai-env v1.24.0

Release date: 2026-10-29

## Summary

Fonts are loaded in CORS mode. A static site's own pages in a sandboxed
`<iframe>` (Docara example frames) have the origin `null`, so the browser
refused the icon font and icons showed as words. Static sites now answer
font files (`woff`, `woff2`, `ttf`, `otf`, `eot`) with
`Access-Control-Allow-Origin: *`, as GitHub Pages does; fonts are public and
sent without credentials. Nosniff and the cache rules stay; every other file
is still same-origin.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

`self update` runs `self migrate`, which adds the font location to static
sites rendered by earlier versions (a backup of each config is kept next to
it, and the old config is restored if `nginx -t` fails).

## Verification

- `static_e2e` (68 checks): the header on fonts with `Origin: null`, nosniff
  and immutable caching on fonts, 404 for a missing font, no CORS header on
  other files, the migration of an older config and its idempotency.
- CI on Ubuntu 22.04, 24.04 and 26.04.
