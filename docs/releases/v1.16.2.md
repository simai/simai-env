# simai-env v1.16.2

Release date: 2026-10-20

## Summary

Let's Encrypt certificates are renewed by two schedules: simai-env's
`/etc/cron.d/simai-certbot` (which reloads nginx) and the distribution's
`certbot.timer` (which did not). When the timer renewed first, nginx kept
serving the old certificate until it expired. simai-env now installs
`/etc/letsencrypt/renewal-hooks/deploy/simai-reload-nginx` (`nginx -t` then a
reload) with every certificate, and `self migrate` adds it on hosts that
already have certificates.

Found while moving renewal of icons.simai.io to http-01.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

`self update` runs `self migrate`, which installs the hook.

## Verification

- CI on Ubuntu 22.04, 24.04 and 26.04.
- `host_e2e` on 24.04 and 26.04 (23 checks: the migration installs an
  executable hook once, and the hook reloads nginx); `upgrade_e2e` and
  `migrate_e2e` on 24.04.
- On the icons.simai.io host: `certbot renew --dry-run` succeeds with the hook.
