# simai-env v1.33.0

Release date: 2026-11-02

## Summary

The first part of Larena Panel stage 5: the administrator manages the
server's services from the panel, and the site wizard learns its options
from the server.

- **Services.** `service:list`, `service:restart {name}`,
  `service:reload {name}`, `service:log {name, lines}` for nginx, PHP-FPM of
  each installed version, MySQL or MariaDB, PostgreSQL, Redis and cron. nginx
  and PHP-FPM test their configuration before a restart or reload, so a
  broken file does not take them down. A failed restart ends with the
  service's last journal lines.
- **Site profiles.** `self:profiles` lists every enabled profile with the
  arguments `site:add` takes for it: which are required, their values or
  pattern, and defaults (PHP versions installed here, database engines).
- **Reverse proxy.** A new `proxy` profile sends a domain to a service on
  this host: `site:add {profile: proxy, upstream-port, upstream-path,
  websockets}`. Only 127.0.0.1, never ports 80 or 443.
- **Bitrix** sites can be created through the panel (`bitrix-files`).
- **Larena Panel 0.3.0** is the pinned build. After this update the panel
  offers it under «Сервер › Обновление» (`self:update-plan {target: panel}`).

Recorded panel answers move to set 9 (79 files).

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
sudo /root/simai-env/simai-admin.sh profile enable --id proxy --confirm yes
sudo /root/simai-env/simai-admin.sh self update --target panel --confirm yes
```
