# simai-env v1.43.2

Release date: 2026-11-06

## Summary

Larena Panel: the server's slow reads answer within the panel's 0.5 s.

- `software:list` and `php:list` keep the answers of slow apt queries
  until the package state changes, so they are never stale: about 0.2 s
  instead of 2.3-2.6 s on the stand. The answers are refilled right after
  simai-env changes packages and every five minutes, which also covers
  unattended upgrades.
- `self:update-plan {target: env}` keeps the update channel's answer for 10
  minutes: about 0.2 s instead of 2.2 s. `software:refresh` and
  `self:update` ask the channel again.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```
