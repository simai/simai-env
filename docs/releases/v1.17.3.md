# simai-env v1.17.3

Release date: 2026-10-20

## Summary

Static sites answered HTML as `text/html` without a charset, while GitHub
Pages sends `text/html; charset=utf-8`. Pages that declare `<meta charset>`
render correctly either way, but a charset-less answer can garble non-Latin
text where the meta tag is missing or late. The static template now sets
`charset utf-8` for HTML, plain text, XML, CSS, JavaScript, JSON and SVG.

`self migrate` (run by `self update`) adds the setting to static sites
created by 1.17.0-1.17.2: once per site, after a backup of the config and an
`nginx -t` check; a failing site is restored and reported.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `static_e2e` (53 checks) on Ubuntu 24.04 and 26.04: HTML and CSS carry
  `charset=utf-8`; a site without it gets it from `self migrate` exactly once,
  and a second run changes nothing. `migrate_e2e`, `upgrade_e2e`.
- CI on Ubuntu 22.04, 24.04 and 26.04.
