# simai-env v1.32.0

Release date: 2026-11-02

## Summary

The last part of Larena Panel stage 4: the administrator updates the server
software and the panel from the panel, and sees what will happen first.

- **Plan.** `self:update-plan {target: env|panel}` shows the installed and
  the available version, the release notes in between, what is backed up,
  what restarts and which sites are checked after. The plan of
  `self:update` carries the same details.
- **Update with a check.** `self:update {target: env}` notes which sites
  answer, replaces simai-env (keeping an archive of the previous release),
  runs host migrations and asks the sites again. If a site that answered
  stops, the previous release comes back and the job fails. Host
  migrations are not undone.
- **Panel.** `self:update {target: panel}` moves the panel to the build this
  release pins: data backup, deploy, health check, and the previous release
  back if the new one does not answer. The database is not rolled back.
- The update job keeps running while the gateway and the panel are
  replaced, and cannot be cancelled midway.

On the command line: `self update-plan`, `self update --check-sites yes`,
`self update --target panel`. Recorded panel answers move to set 8.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```

## Verification

  `self:update` changes nothing, a successful update job checks the sites,

- `panel_install_e2e`: the panel update plan shows the installed and the
