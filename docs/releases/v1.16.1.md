# simai-env v1.16.1

Release date: 2026-10-20

## Summary

- `ssl install` and `ssl letsencrypt` (and renew/remove) failed on sites with
  the new `node` profile: "Unsupported nginx template id: node". The template
  is now known, and every re-render of a service site keeps its port.
- `ssl install` builds the certificate bundle without duplicate
  intermediates: chain certificates already present in the certificate (a
  fullchain), or a chain kept from an earlier attempt, are not appended again.

Found during the TLS step of the icons.simai.io move.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- CI on Ubuntu 22.04, 24.04 and 26.04 (169 commands).
- `node_e2e` on 24.04 and 26.04 with TLS: 33 checks (certificate signed by a
  test CA, fullchain plus `--chain` gives two certificates, proxy port kept,
  HTTPS reaches the service, the service sees `X-Forwarded-Proto: https`,
  HTTP redirects to HTTPS); `nginx_tests` 40 checks.

## Rollback

Restore the pre-update archive printed by `self update`.
