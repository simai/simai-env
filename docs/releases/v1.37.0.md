# simai-env v1.37.0

Release date: 2026-11-04

## Summary

Larena Panel, the «Software» section, part 1: PHP.

- **Versions side by side.** `php:list` shows every installed PHP version
  with the sites on it, waiting package updates, and the versions that can
  be installed. `php:install` adds a version without touching any site; a
  site moves with `site:set-php`.
- **Remove only what is free.** `php:remove` refuses a version a site uses
  (and names the sites), the system version of the Ubuntu release, and the
  version behind the `php` command.
- **Extensions.** `php:extension {php, name, enabled}` turns an extension on
  or off for PHP-FPM and installs its package when needed; if PHP-FPM
  rejects the change, the previous state comes back.
- **Updates.** `php:update` installs fixes within the version (8.3.6 to
  8.3.7), never a new version, restarts PHP-FPM and asks the sites on that
  version before and after. A site that stops answering fails the job.

All PHP actions in the gateway are administrator only.

Recorded panel answers move to set 13.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```
