# simai-env v1.12.77

Release date: 2026-08-03

## Summary

Bitrix archive restore preparation is now compatible with the supported PHP 8
baseline. Restore mode pre-fills `.settings.php` and connection initialization
from the managed site database metadata, but leaves `dbconn.php` to the backup
archive. This prevents a modern UTF-8 backup from being blocked by the obsolete
`mbstring.func_overload=2` check before its Bitrix version file is unpacked.

Fresh Bitrix installation remains unchanged: setup mode still creates the full
DB preseed, including `dbconn.php` and `SHORT_INSTALL`.

The release also makes menu cancellation easier to understand: the final site
creation confirmation explains both choices, and cancellation logs identify the
wizard step and domain while preserving the default-safe `no` behavior.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update
```

No database or PHP-FPM migration is required. A site prepared for restore by an
older release may still contain a generated preseed `dbconn.php`; back it up and
move it outside the document root before retrying the restore wizard.

## Rollback

The self-update flow retains its verified pre-update archive and automatically
rolls back a failed activation. Restoring a pre-1.12.77 release does not alter
existing sites, but future restore preparation will again create the premature
`dbconn.php` and should not be used for new PHP 8 archive restores.
