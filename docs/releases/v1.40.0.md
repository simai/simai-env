# simai-env v1.40.0

Release date: 2026-11-05

## Summary

Larena Panel, the file manager, part 2.

- **Upload.** `file:upload` puts any file up to 1 GiB into a site. The file
  travels after the request line like a release archive, is checked against
  its sha256, and never replaces an existing file unless asked.
- **Pack.** `file:archive` packs a file or directory into a `.zip`,
  `.tar.gz`, `.tgz` or `.tar`. Links are stored as links, never followed.
- **Unpack.** `file:extract` unpacks into a directory: files and directories
  only, links skipped. An entry that would land outside the destination
  refuses the whole archive, so do archives with too many entries or bytes.
  Existing files are not overwritten unless asked.

As before, everything runs as the site's user inside the site directory;
owners use it on their own sites.

Recorded panel answers move to set 16.
