# simai-env v1.35.0

Release date: 2026-11-03

## Summary

Larena Panel stages 5.2 and 5.3: the firewall and access to the panel by
address, without the risk of locking yourself out.

- **Firewall.** `firewall:status` shows the rules (ufw) with stable ids, the
  blocked addresses and the change waiting for confirmation.
  `firewall:rule-add {port, proto, from, action}` and `firewall:rule-remove
  {id}` open or close ports; `firewall:block {address, ttl}` and
  `firewall:unblock` deny everything from an address or network, for a while
  or until removed. IPv4 and IPv6.
- **Panel access.** `panel:access {allow}` lets only these addresses open
  the panel; `any` removes the limit.
- **Undone unless confirmed.** Each change saves the previous rules first.
  Unless it is confirmed within two minutes (`change:confirm {change_id}`),
  the server puts them back by itself, also after a reboot. A change that cuts
  the panel off cannot be confirmed from it, so it undoes itself.
- **Always open.** SSH, HTTP and HTTPS cannot be closed for everyone, and the
  host itself and certificate checks always reach the panel.

Recorded panel answers move to set 11.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```

The firewall commands need ufw: `self firewall-ensure --confirm yes`.

## Verification

- `firewall_e2e` (new): a confirmed change stays, an unconfirmed one is undone
  by its timer, and by the status refresh when the timer is gone; a second
  change waits for the first; SSH and HTTPS cannot be closed; rules by id and
  from a network; IPv4 and IPv6 blocks, an expiring block, block order; panel
  access through the gateway as a list and a comma list, an older nginx file
  gets the include, local checks and certificate checks pass, undo opens the
  panel again.
- Ubuntu 22.04, 24.04 and 26.04.
