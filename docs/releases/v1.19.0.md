# simai-env v1.19.0

Release date: 2026-10-28

## Summary

`site add --profile redirect` used to send the path and query to the target,
which suits a renamed site but not a retired one: the old pages answer 404 on
the new site. `--redirect-path drop` sends every request to the target's root
page instead:

```bash
sudo /root/simai-env/simai-admin.sh site add --domain gone.example.com --profile redirect \
  --redirect-to https://new.example.com --redirect-path drop --confirm yes
```

`keep` remains the default. The mode is stored with the site, survives
certificate installs and other re-renders, and is shown by
`site redirect-list`. Redirect sites created before 1.19.0 keep their path.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `static_e2e` (61 checks) on Ubuntu 24.04 and 26.04: `drop` answers 301 to the root page
  for any path and query, also after `ssl install`; unknown modes are refused;
  `keep` redirects are unchanged.
- CI on Ubuntu 22.04, 24.04 and 26.04.
