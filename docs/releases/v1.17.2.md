# simai-env v1.17.2

Release date: 2026-10-20

## Summary

`site redirect-add` rendered `return <code> <to>;`, and nginx's `return` does
not append the query string, so `/?utm_source=x` lost its parameters on the
way to `/ru/`. Redirects now append `$is_args$args` unless the target sets a
query of its own. Existing redirects pick it up on the next re-render or the
next `redirect-add`.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `static_e2e` (48 checks) asserts `/?utm_source=x&a=1` -> `/ru/?utm_source=x&a=1`.
- CI on Ubuntu 22.04, 24.04 and 26.04.
