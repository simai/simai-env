# simai-env v1.17.1

Release date: 2026-10-20

## Summary

On hosts where every site runs as the shared `simai` account
(`SIMAI_SITE_ISOLATION=no`), the first static deploy through the CI gate
failed its health check with 403: the release was extracted by the site user
with its own primary group (`simai`) and a restrictive umask, and nginx reads
through `www-data`. The failed release was rolled back as designed.

`site deploy` now gives every fetched release (archive, git or directory) the
site's web group and group read/traverse permissions before it is checked
and switched. Other users still get no access.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```
