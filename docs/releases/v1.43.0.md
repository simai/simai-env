# simai-env v1.43.0

Release date: 2026-11-05

## Summary

Larena Panel: «Программы» as a catalogue of server programs.

- **One list.** `software:list` answers 17 programs in six groups (web,
  security, databases, cache, languages, tools): title, one-line purpose,
  installed and candidate versions, state (`running`, `stopped`,
  `installed`, `not_installed`) and which of install, update and remove are
  allowed. When one is not, `install_blocked` / `remove_blocked` say why
  with a code the panel translates, and name the sites that need it.
- **Install and update.** `software:install` adds any installable program
  (Redis, Memcached and ImageMagick with their PHP extension for every PHP
  version) and updates an installed one alone.
- **Remove.** `software:remove` removes a program and keeps its
  configuration and data. It is refused while sites need the program
  (Node.js, Apache, PostgreSQL), while Certbot renews certificates, for what
  simai-env itself needs (nginx, MySQL, PHP, Composer, Git), and when apt
  would take a package the server needs along with it.
- Both plans carry the program's catalogue row, so the panel can say what
  changes, what is kept and why it would be refused.

Administrator only. Recorded panel answers move to set 20.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```
