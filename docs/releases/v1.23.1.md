# simai-env v1.23.1

Release date: 2026-10-29

## Summary

The `install.sh` part of 1.23.0 was left out of that release. With it, a
new server gets SIMAI ENV Panel during installation:

```bash
SIMAI_INSTALL_PANEL_DOMAIN=panel.example.com SIMAI_INSTALL_PANEL_EMAIL=ops@example.com \
  bash install.sh
```

The installer runs `panel install --domain <domain> --confirm yes` (with
`--ssl-email` when the email is set) after bootstrap; a failure is reported
with the command to run later and does not stop the installation.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `bash -n install.sh`; `panel install` itself is covered by
  `panel_install_e2e` (1.23.0).
- CI on Ubuntu 22.04, 24.04 and 26.04.
