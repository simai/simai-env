# simai-env v1.31.0

Release date: 2026-11-01

## Summary

The second part of Larena Panel stage 4: the server watches itself, so
warnings arrive even when nobody has the panel open, or when the panel itself
is down.

- **Alerts.** Every five minutes the server checks its disks, certificates,
  sites, backups and the panel. An alert opens when a disk is 90% full, a
  certificate has less than 14 days left or did not renew, a site or the panel
  does not answer (or answers 5xx) twice in a row, a site has no backup for 48
  hours, or a backup or a backup check failed. The same problem keeps one
  alert; it can be acknowledged and is resolved when the problem is gone.
  `self:alerts`, `self:alerts-ack {id}`.
- **Delivery.** New and resolved alerts go to a webhook (JSON) or a Telegram
  chat: `self:alerts-channel {kind, target, token}`, `self:alerts-test`. The
  bot token stays root-only on the server and never comes back.
- **Load history.** `self:metrics-history {period: day|week|month}`: 5-minute
  points for a day, hourly for a week or a month, 30 days back. The panel no
  longer needs to keep samples itself.

Recorded panel answers move to set 7 (65 files), with one planted alert. Set
6 had pinned `args.backup` of every command; `plan.site-add-no-backup.json`
now shows `backup: no`.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

The watch starts with the next five-minute status run; no setting is needed.
