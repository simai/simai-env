# simai-env v1.38.0

Release date: 2026-11-04

## Summary

Larena Panel, the «Software» section, part 2: the rest of the server.

- **What is installed.** `software:list` shows nginx, the MySQL server,
  PostgreSQL, Redis, Node.js and certbot with their versions and waiting
  updates, the node sites, and the system updates: how many, how many are
  security fixes, which are kept back, and whether a reboot is pending.
- **System updates.** `software:refresh` refreshes the apt index;
  `software:update` (all or `security-only`) upgrades installed packages
  only, keeps changed configuration files, tests nginx and PHP-FPM and asks
  every site before and after. Its plan lists the waiting packages. A site
  that stops answering fails the job with its name. The server is never
  rebooted by the update.
- **Install.** `software:install {name: node|redis|postgresql, version}`.
  Redis comes with its PHP extension for every PHP version; Node.js from the
  pinned NodeSource repository, one per server, so a major change is refused
  while node sites exist.

All software actions in the gateway are administrator only.

Recorded panel answers move to set 14.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```
