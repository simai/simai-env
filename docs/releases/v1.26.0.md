# simai-env v1.26.0

Release date: 2026-10-31

## Summary

Larena Panel is public (`simai/larena-env`, Apache-2.0), and simai-env installs
it with one command:

```bash
sudo /root/simai-env/simai-admin.sh panel install --domain panel.example.com --ssl-email ops@example.com --confirm yes
# or together with the server:
bash install.sh --with-panel --panel-domain panel.example.com --panel-email ops@example.com
```

- Each simai-env release pins one panel version and its sha256 in
  `admin/panel-release.env`; this one pins 0.2.0. A download that does not
  match is refused before anything changes. `--version V --sha256 S` chooses
  another release.
- `panel update` moves to the pinned version, does nothing at that version and
  never steps back without `--version`. `self update` does not update the panel
  by itself.

## Changed behaviour

`panel install --domain D` without a source used to install the placeholder. It
now downloads the build; use `--placeholder yes` for the placeholder.
`SIMAI_INSTALL_PANEL_DOMAIN` follows the same default.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```

## Verification

- `panel_install_e2e`: the pinned download with a wrong and a right checksum,
  update to a new pin, no step back, `--version`, the published 0.2.0 build
  answering `/up`.
- CI on Ubuntu 22.04, 24.04 and 26.04.
