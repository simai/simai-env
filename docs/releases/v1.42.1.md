# simai-env v1.42.1

Release date: 2026-11-05

## Summary

Larena Panel: the update plan in the reader's language.

- **Codes next to texts.** `self:update-plan` adds `backup_item {kind:
  env_scripts|panel_data, path}`, `restart_items [{kind:
  php_fpm_pool|queue_workers|service, target}]` and `rollback_kind:
  env_release|panel_release`. The panel translates them; the English texts
  stay for older panels.
- **The panel build's own version.** A panel installed from its own archive
  is compared by the `version` in its `panel-build.json`, so an older
  pinned build is not offered as an update.

Recorded panel answers move to set 19.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```

## Verification

- `panel_e2e`: the env plan carries `backup_item` and `rollback_kind`.
- `panel_install_e2e`: a build with `panel-build.json` is compared by its
  own version and the panel plan carries the codes.
