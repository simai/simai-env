# simai-env v1.21.0

Release date: 2026-10-29

## Summary

Second stage of the gateway for SIMAI ENV Panel
(`docs/architecture/panel-gate.md`).

- **Data a panel shows.** `site describe` and `self describe` now include the
  certificate nginx serves for each site: names, issuer, expiry, days left,
  auto-renewal. `site describe` lists the site's data backups (date, size,
  parts, checksums, encryption) and their daily schedule.
  `logs nginx --output json` returns the last lines as data.
- **Actions with a plan.** Through the gateway an action first answers what
  it would do. With `confirm` it starts as a job: a transient systemd unit
  that outlives the panel, with status, a live log with a cursor,
  cancellation and a list of recent jobs. Owners act and see jobs only on
  their own sites.
- Actions available: Let's Encrypt certificate and renewal, deploy rollback,
  data backup, queue worker restart, node service restart.

Command-line use is unchanged; the new fields are additions to the JSON.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --confirm yes
```
