# simai-env v1.42.0

Release date: 2026-11-05

## Summary

Larena Panel: Apache mode for PHP sites that rely on `.htaccess`.

- **One switch per site.** `site:apache {domain, enable}` moves a PHP site
  (`generic`, `laravel`, `wordpress`, `bitrix`) behind Apache, or back to
  nginx only. Apache is installed the first time it is needed.
- **nginx stays in front.** HTTPS, access rules, own directives,
  certificates and the health check keep working as before; Apache listens
  on `127.0.0.1:8088` only and receives the real client address and scheme
  from nginx.
- **Same PHP.** Apache runs PHP through the site's own PHP-FPM pool, so the
  PHP version, the user the site runs as and PHP settings stay the same.
- **Safe switch.** If Apache rejects the configuration, or the site stops
  answering, everything is put back.
- `site:describe` shows `web_server`; `software:list` shows Apache.

Administrator only. Recorded panel answers move to set 18.

## Update

```bash
sudo /root/simai-env/simai-admin.sh self update --check-sites yes --confirm yes
```
